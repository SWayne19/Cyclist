# Cyclist

A modern, responsive bicycle shop website showcasing premium bikes, collections, and cycling content.

## Features

- **Responsive Navigation** — Sticky navbar with mobile hamburger menu, search toggle, and smooth scroll to sections
- **Image Slideshow** — Auto-playing hero slider with previous/next controls and dot navigation
- **New Arrivals** — Highlighted product cards with ratings, prices, and quick-action buttons (wishlist, cart, view)
- **Collections** — Curated bike collections (Urban Explorer, Adventure Series, Performance Road)
- **Product Catalog** — 12 products filterable by category (Road, Mountain, City) with animated show/hide transitions
- **Blog Section** — Cycling tips, maintenance guides, and travel destination articles
- **Newsletter** — Email subscription form
- **Footer** — About info, useful links, contact details, social media links, and payment method icons

## Tech Stack

- **HTML5** — Semantic markup, single-page layout
- **CSS3** — Custom styles with Poppins font, responsive design, transitions and animations
- **Vanilla JavaScript** — DOM manipulation, slideshow logic, product filtering, scroll effects
- **Font Awesome 6** — Icons throughout the UI

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open `index.html` in your browser, or serve with any static file server:
   ```bash
   # Example using Python
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser.

No build tools or dependencies required — it's pure HTML, CSS, and JavaScript.
